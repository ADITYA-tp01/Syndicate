## The Problem

Fraud lives in *connections*, not rows. 2,289 suspects hide three engineered rings. Vector RAG cannot walk a 5-hop money trail or cluster shared devices/IPs. A knowledge graph can.

---

## How It Works (GraphRAG pipeline)

1. **Graph algorithms** — FalkorDB Cypher extracts person-person links (shared device, shared IP, money). Backend union-find (WCC) isolates rings. Money-inflow centrality ranks the ringleader.
2. **Identity resolution** — Dual-entity match: persons sharing BOTH a device AND an IP.
3. **Evidence trail** — Variable-length `[:TRANSFERRED_TO*1..5]` money traces.
4. **AI Investigation Brief** — LLM narrates graph evidence with the exact Cypher queries as data sources.

---

## Graph Data Model

```cypher
(:Person      {id, name, email, created_at})
(:Device      {id, fingerprint, os})
(:IP          {address, geo, is_proxy})
(:BankAccount {number, type})

(:Person)-[:USES_DEVICE   {first_seen}]->(:Device)
(:Person)-[:LOGGED_FROM   {at}]->(:IP)
(:Person)-[:OWNS]->(:BankAccount)
(:BankAccount)-[:TRANSFERRED_TO {amount, at}]->(:BankAccount)
```

## Setup

### Option A — local (dev)

```bash
# 1. Graph DB
docker run -p 6379:6379 -d --name syndicate-falkordb falkordb/falkordb:latest

# 2. Seed (Python)
pip install -r scripts/requirements.txt
python scripts/seed.py
python scripts/verify_seed.py

# 3. App (Ollama for AI briefs, see below)
npm install
npm run dev
```

Open http://localhost:3000

### Option B — docker compose (judge path)

```bash
cp .env.example .env   # optional OPENAI_API_KEY for briefs
docker compose up --build
```

FalkorDB :6379 · app :3000. Seed runs once, then the web service starts.

> **Cross-platform note:** `@next/swc-win32-x64-msvc` is a Windows-only native binary and is declared as an `optionalDependency` in `package.json`. On Linux (the Docker judge image) `npm ci` skips it and Next.js falls back to its bundled JS SWC compiler. On Windows it installs and is used for faster local dev.

### Option C — live deployment

Stretch. Local docker-compose is the submission path if FalkorDB Cloud is unavailable.

## AI Briefs (GraphRAG)

The Investigation Brief is generated by an LLM that narrates the graph evidence. Two providers are supported, tried in order:

1. **Ollama** (local, no key) — default. Install Ollama and pull a model:
   ```bash
   ollama serve
   ollama pull qwen2.5-coder:7b
   ```
   Configure via env: `OLLAMA_URL` (default `http://localhost:11434`), `OLLAMA_MODEL` (default `qwen2.5-coder:7b`).
2. **OpenAI** — fallback if `OPENAI_API_KEY` is set. Uses `gpt-4o-mini`.

Local inference takes ~100–120 s per brief. For a live demo, either set `OPENAI_API_KEY` or pre-generate the brief before recording.

The brief's **Data Sources** section cites the exact Cypher queries that produced each claim, rendered from `lib/queries.ts` (not from the LLM's prose) so the citations are guaranteed accurate.

---

## Cypher (hero queries)

All queries live in `lib/queries.ts`. Highlights:

- **Identity resolution (dual entity)** — persons sharing device **and** IP
- **Shared device / IP detection** — grouped: device → [person_ids], [person_names]
- **Money trail** — `[:TRANSFERRED_TO*1..5]`
- **Ring isolation** — person-person links via device / IP / money, clustered by union-find in `lib/graph-algos.ts`
- **Ringleader** — money-inflow centrality (kingpin of Ring Gamma ranks #1 with $951K inflow)
- **Ego network** — 1-2 hop neighborhood from a seed person
